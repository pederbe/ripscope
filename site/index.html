Install Ripscope

Install Ripscope.
Start exploring.

The install script, on Linux or Windows, installs Ripscope and sets up Vim, Neovim and Emacs in one step. So does one line in your plugin manager. Then open a C file in your project and search: the first search indexes it.

The packages and source builds install the executable alone.

Installation guide →

Linux install script

curl -fsSL https://ripscope.com/install.sh | sh

Checksum-verified download into ~/.local/bin. Vim loads Ripscope by itself, and so does Neovim unless lazy.nvim manages its plugins. For Emacs and lazy.nvim, the script prints the one line to add. Linux x86-64, glibc 2.28 or newer.

Windows PowerShell

irm https://ripscope.com/install.ps1 | iex

Checksum-verified native x86-64 download, with Vim, Neovim and Emacs set up as on Linux. No WSL or separate Visual C++ runtime.

One line in your editor

{ 'pederbe/ripscope', branch = 'release', build = ':RipscopeInstall' },
Plug 'pederbe/ripscope', { 'branch': 'release', 'do': ':RipscopeInstall' }
(use-package ripscope :vc (:url "https://github.com/pederbe/ripscope" :branch "release" :lisp-dir "contrib/emacs" :rev :newest) :config (ripscope-setup))

Neovim with lazy.nvim, Vim with vim-plug and Emacs 30 or newer. Each line installs the plugin and, through its build step, the executable of the same release.

Debian / Ubuntu package

curl -fLO https://github.com/pederbe/ripscope/releases/download/v@VERSION@/ripscope_@VERSION@_amd64.deb &&
curl -fLO https://github.com/pederbe/ripscope/releases/download/v@VERSION@/ripscope_@VERSION@_amd64.deb.sha256 &&
sha256sum -c ripscope_@VERSION@_amd64.deb.sha256 &&
sudo apt install ./ripscope_@VERSION@_amd64.deb

Package for Linux x86-64, with the executable alone: the Plugin manager tab has the line that sets up your editor. The matching .deb.sha256 sidecar verifies the download before installation. Package verification instructions.

Fedora / RHEL package

curl -fLO https://github.com/pederbe/ripscope/releases/download/v@VERSION@/ripscope-@VERSION@-1.x86_64.rpm &&
curl -fLO https://github.com/pederbe/ripscope/releases/download/v@VERSION@/ripscope-@VERSION@-1.x86_64.rpm.sha256 &&
sha256sum -c ripscope-@VERSION@-1.x86_64.rpm.sha256 &&
sudo dnf install ./ripscope-@VERSION@-1.x86_64.rpm

Package for Linux x86-64, with the executable alone: the Plugin manager tab has the line that sets up your editor. The matching .rpm.sha256 sidecar verifies the download before installation. Package verification instructions.

Build from source

cargo install --locked --git https://github.com/pederbe/ripscope.git

Requires stable Rust and a C compiler. On Windows, use the MSVC Build Tools and Windows SDK.
